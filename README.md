#Readme for Margetts-Smith et al., Anterior thalamic nucleus inputs to the retrosplenial cortex are unperturbed in the hAPP-J20 mouse model of Alzheimer’s disease. 
##Preprint at [BioRxiv](https://www.biorxiv.org/content/10.64898/2025.12.01.691675v1)

This repository contains code and data for our publication studying anterior thalamic cortex inputs to retrosplenial cortex in the J20-hAPP mouse line. All numerical data analysed in the manuscript are contained herein:
1. J20 Fos data
2. J20 plagque data using AmyloGlo and IHC for Abeta1-42
3. Electrophysiology data (J20.sav for EPSC, and J20_PPR_ISI for the paired pulse ratio data)
